# 时间方块

把一天分成 96 个 15 分钟的方块：浅蓝是还没到的时间，浅粉是已经过去的时间。点蓝色方块可以安排任务、写备注。

- 纯前端，没有服务器，数据只存在手机浏览器本地（localStorage）
- 用 Service Worker 缓存页面，第一次打开后，没网也能用
- 右上角“⋯”里可以导出 / 导入备份文件

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 整个应用：界面、样式、逻辑 |
| `sw.js` | Service Worker，负责离线缓存 |
| `manifest.webmanifest` | 应用名称、图标、全屏显示等设置 |
| `icons/` | 主屏幕图标 |

## 更新应用

修改 `index.html` 后，把 `sw.js` 第 5 行的 `timeblocks-v1` 改成 `timeblocks-v2`（依次递增），再上传。
手机联网打开一次后，后台会下载新版本，再下一次打开就生效了。
